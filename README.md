# Rehabilitation Assessment Research Monorepo

This repository holds several related research threads on skeleton-based rehabilitation-exercise
assessment. It is not a single paper's codebase — it is a working research directory that has grown
several projects over time. This README is the map: what lives where, and which thread is the current
focus.

## Current primary project: SE(3)-Equivariant Neural Recurrence (WACV 2026)

**"Viewpoint Invariance Is a Theorem, Not a Fit"** — an SE(3)-equivariant recurrent model (EGRU) whose
viewpoint invariance is a certified theorem rather than a learned/augmented property, evaluated with a
strict subject-disjoint protocol against a point-cloud-transformer baseline and hand-crafted-invariant
controls.

- Paper source: [`paper/wacv_submission/`](paper/wacv_submission/) (compile: `pdflatex paper_wacv.tex` twice)
- Design rationale / theory: [`docs/reference/PROJECT_BRIEF.md`](docs/reference/PROJECT_BRIEF.md)
- Project working notes for AI-assisted development: [`CLAUDE.md`](CLAUDE.md)
- Reviewer response: [`docs/reviews/`](docs/reviews/)
- Live 3-act demo (EGRU vs. transformer under camera rotation): [`demo/`](demo/) — see `demo/README.md`

Core model/training/certification code lives in [`src/`](src/) — see below for the file map.

## Code map (`src/`)

The package is flat (no subpackages) — every script does `sys.path.insert(0, <this dir>)` and imports
siblings directly, so keep new files at the top level of `src/`. Rough groupings by filename prefix/theme:

| Theme | Representative files |
|---|---|
| Core model | `equivariant_gru.py` (EGRU), `cde_model*.py` (Neural CDE variants, dropped), `models_curvenet.py` (PCT baseline), `models_stgcn.py`, `invariant_controls.py` (hand-crafted InvariantGRU control) |
| Data loading | `kimore_cde_data.py`, `ntu_dataset.py`, `load_rehab246.py`, `load_uiprmd_validity.py`, `prepare_kimore.py`, `prepare_uiprmd.py` |
| Training | `train_egru.py`, `train_baseline_pct.py`, `train_cde.py`, `train_rehab246.py`, `train_stream_egru.py` |
| Certification / equivariance audit | `certify_egru.py`, `certify_mp.py`, `certify_phase1.py`, `certify_trainable.py`, `equivariance_suite.py`, `determinism.py` |
| Robustness experiments | `joint_failure.py`, `resilience_sweep.py`, `corruption_pipeline.py`, `irregular_data.py`, `bandwidth_law.py`, `block2_transforms.py`, `block23_experiments.py` |
| Protocol / statistics audit | `protocol_null.py` (bootstrap CI, epoch-selection-bias audit), `protocol_inflation.py`, `pooled_bootstrap_eval.py`, `seed_distribution.py` |
| Deployment | `int8_quant_budget.py`, `precision_budget.py`, `ttfs_benchmark.py` (if present), streaming variants |
| Aggregation / reporting | `aggregate_final.py` (regenerates every number in the paper from banked JSON — the source of truth for tables), `generate_tables.py`, `make_figures.py` |
| Older Paper-2 SSL pipeline | `src/selfsup/` — contrastive/masked pretraining, zero-shot cross-sensor eval (see "Other research threads" below) |

If a script's purpose isn't obvious from the name, check its module docstring — most files here open with a
paragraph explaining what question the script answers and why it exists.

## Other research threads in this repo

- **Paper 2 — SSL cross-sensor transfer (definitive negative result).** SSL pretraining does not rescue
  zero-shot cross-sensor rehabilitation scoring. Code: `src/selfsup/`. Writeup:
  [`paper/archive/manuscript.tex`](paper/archive/manuscript.tex) /
  [`paper/archive/manuscript.md`](paper/archive/manuscript.md). Full 78-fold LOSO results:
  [`archive/legacy_results/`](archive/legacy_results/).
- **EGNN/canonicalization sandbox** (`research_egnn/`) — isolated comparison of a lighter E(n)-equivariant
  encoder and PCA-canonicalization against the steerable EGRU encoder. Not part of the WACV submission's
  main claims; see `research_egnn/README.md` and `FINDINGS.md`.
- **Transformer_Rehabilitation/** — a separately-cloned reference implementation (has its own `.git`),
  kept for comparison/reference. Not part of this repo's git history.

```bash
pip install -r requirements.txt
cp .env.example .env   # fill in any required values
```

## Getting the data

Raw/processed dataset directories (`KIMORE*/`, `REHAB246/`, `UIPRMD_processed/`, `Segmented Movements/`,
etc.) are gitignored or only partially tracked and are **not** fetched by cloning this repo. Use:

```bash
python scripts/download_and_prepare.py   # KIMORE + related prep
python scripts/prepare_ntu.py            # NTU RGB+D Cross-View
```

or see each dataset loader's module docstring in `src/` for manual acquisition steps.
